---
##  Descrição do portfolio

    Desenvolver um Portfólio Profissional completo, com HTML5, Bootstrap e publicá-lo no GitHub Pages 
    para que todos possam navegar pelo portfólio. O propósito é integrar componentes como Navbar,
    Carousel, Cards de projetos, ícones com Devicon e formulários de contato exige atenção à estrutura de
    pastas e às classes utilitárias.

## 💻 Sintaxe do projeto

    👩‍💻 O portfólio é uma página única com menus de navegação.
    
    👩‍💻 Cada opção direciona o visitante a uma seção específica.

    👩‍💻 O Bootstrap foi utilizado para estruturar o layout, organizar as colunas e criar um menu responsivo.

    👩‍💻 O JavaScript controla as interações da página.
